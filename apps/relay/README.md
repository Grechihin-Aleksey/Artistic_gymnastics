# Ретранслятор

Облачная часть системы. Принимает снимки результатов от сервера в зале и раздаёт их сайту. Зрители подключаются только к ретранслятору, поэтому сколько бы людей ни смотрело сайт, нагрузка на зал и его интернет не растёт.

## Запуск

```sh
docker build -f apps/relay/Dockerfile -t ag-relay .
docker run -d --restart unless-stopped -p 8080:8080 \
  -e RELAY_TOKEN=длинный-случайный-токен -v ag-relay-data:/data ag-relay
```

Поставьте перед ним HTTPS (nginx, Caddy или балансировщик хостинга). Для nginx отключите буферизацию потока событий: ретранслятор сам отправляет заголовок `X-Accel-Buffering: no`.

| Переменная | Назначение |
| --- | --- |
| `RELAY_TOKEN` | Токен, с которым сервер в зале присылает результаты, не короче 16 символов. Тот же токен задаётся в `RELAY_TOKEN` сервера в зале |
| `PORT` | Порт, по умолчанию 8080 |
| `DATA_DIR` | Куда сохранять последние снимки, чтобы пережить перезапуск |
| `WIDGET_DIST` | Сборка `apps/scoreboard`, раздаётся как виджет |

## Адреса

| Метод | Путь | Кто | Что делает |
| --- | --- | --- | --- |
| POST | `/ingest/:id` | сервер в зале, `Authorization: Bearer <RELAY_TOKEN>` | Принимает снимок `{ snapshot, approved }`. Снимок старше уже сохранённого игнорируется |
| GET | `/api/competitions` | все | Соревнования, по которым есть результаты, свежие сверху |
| GET | `/api/competitions/:id` | все | Последний снимок результатов |
| GET | `/api/competitions/:id/events` | все | Поток Server-Sent Events: при подключении `snapshot`, затем `snapshot` на каждое изменение и `approved` на каждую утверждённую оценку |
| GET | `/widget/` | все | Виджет результатов (табло в светлой или тёмной теме) |
| GET | `/embed.js` | все | Скрипт встраивания виджета на страницу сайта |

Все открытые адреса разрешают запросы с любых сайтов (CORS), так что результаты можно выводить и своей вёрсткой через `/api/competitions/:id/events`.

## Встраивание

```html
<div data-ag-results="ID соревнования" data-view="auto" data-theme="light"></div>
<script src="https://АДРЕС-РЕТРАНСЛЯТОРА/embed.js" async></script>
```

Скрипт вставляет виджет в рамке и сам подгоняет её высоту под содержимое.
