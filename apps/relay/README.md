# Ретранслятор

Облачная часть системы. Принимает снимки результатов от сервера в зале и раздаёт их сайту. Зрители подключаются только к ретранслятору, поэтому сколько бы людей ни смотрело сайт, нагрузка на зал и его интернет не растёт.

## Запуск

```sh
docker build -f apps/relay/Dockerfile -t ag-relay .
docker run -d --restart unless-stopped -p 8080:8080 \
  -e RELAY_TOKEN=длинный-случайный-токен -v ag-relay-data:/data ag-relay
```

Поставьте перед ним HTTPS (nginx, Caddy или балансировщик хостинга). Для nginx отключите буферизацию потока событий: ретранслятор сам отправляет заголовок `X-Accel-Buffering: no`.

| Переменная | Назначение |
| --- | --- |
| `RELAY_TOKEN` | Токен, с которым сервер в зале присылает результаты, не короче 16 символов. Тот же токен задаётся в `RELAY_TOKEN` сервера в зале |
| `PORT` | Порт, по умолчанию 8080 |
| `DATA_DIR` | Куда сохранять последние снимки, чтобы пережить перезапуск |
| `WIDGET_DIST` | Сборка `apps/scoreboard`, раздаётся как виджет |

## На обычном PHP-хостинге (без VPS)

Если сайт на обычном хостинге (Beget и подобные) и держать там постоянно работающую программу нельзя, есть PHP-версия ретранслятора в `php/`. Она умеет то же самое: результаты, онлайн-заявки, протоколы. Разница одна: зрители не держат открытое соединение, а переспрашивают ретранслятор раз в несколько секунд (`$RELAY_POLL_SECONDS` в `config.php`, по умолчанию 3), поэтому оценка появляется на сайте с задержкой до этого интервала.

```sh
pnpm --filter @ag/scoreboard build && pnpm --filter @ag/relay build:php
```

Получится `dist-php/ag-relay-php.zip` с папкой `results`; готовый архив лежит и в `downloads/` в корне репозитория. Её нужно распаковать в корень сайта, вписать токен в `results/config.php`, а на ноутбуке в зале указать `RELAY_URL=https://сайт/results/`. Нужен PHP 7.4 или новее с `mod_rewrite`, база данных не требуется: данные лежат в `results/data`, каждый файл начинается с `<?php exit; ?>` и по прямому адресу не открывается.

Сервер в зале шлёт токен и в `Authorization`, и в `X-Relay-Token`: некоторые хостинги не передают `Authorization` в PHP.

Проверка без Apache: `php -S 127.0.0.1:8090 php/dev-router.php` (переменные `RELAY_TOKEN`, `RELAY_DATA_DIR`).

## Адреса

| Метод | Путь | Кто | Что делает |
| --- | --- | --- | --- |
| POST | `/ingest/:id` | сервер в зале, `Authorization: Bearer <RELAY_TOKEN>` | Принимает снимок `{ snapshot, approved }`. Снимок старше уже сохранённого игнорируется |
| PUT | `/entries/:id` | сервер в зале | Опубликовать приём онлайн-заявок: `{ key, call: { name, discipline, open, deadline, categories }, decisions? }`; `decisions` — решения по заявкам для клубов |
| PUT | `/protocols/:id` | сервер в зале | Выложить протоколы `{ files: [{ file, title, group, data }] }` (data в base64), заменив прежние |
| DELETE | `/protocols/:id` | сервер в зале | Снять протоколы |
| GET | `/api/competitions/:id/protocols` | все | Список выложенных протоколов |
| GET | `/api/competitions/:id/protocols/:file` | все | Файл протокола (PDF открывается в браузере, Excel скачивается) |
| GET | `/entries/:id` | сервер в зале | Все присланные заявки |
| GET | `/api/entries/:id?k=<ключ>` | клуб по ссылке | Сведения о приёме: название, срок, разряды |
| POST | `/api/entries/:id?k=<ключ>` | клуб по ссылке | Подать заявку: клуб, город, контакт, участники (до 100). Закрытый приём или вышедший срок — 409 |
| GET | `/api/entries/:id/:entryId?k=<ключ>` | клуб по ссылке | Статус заявки: на рассмотрении, принята или отклонена с причиной |
| GET | `/entry/` | клубы | Форма заявки; ссылку с ключом выдаёт секретариат |
| GET | `/api/competitions` | все | Соревнования, по которым есть результаты, свежие сверху |
| GET | `/api/competitions/:id` | все | Последний снимок результатов |
| GET | `/api/competitions/:id/events` | все | Поток Server-Sent Events: при подключении `snapshot`, затем `snapshot` на каждое изменение и `approved` на каждую утверждённую оценку |
| GET | `/widget/` | все | Виджет результатов (табло в светлой или тёмной теме) |
| GET | `/embed.js` | все | Скрипт встраивания виджета на страницу сайта |

Все открытые адреса разрешают запросы с любых сайтов (CORS), так что результаты можно выводить и своей вёрсткой через `/api/competitions/:id/events`.

## Встраивание

```html
<div data-ag-results="ID соревнования" data-view="auto" data-theme="light"></div>
<script src="https://АДРЕС-РЕТРАНСЛЯТОРА/embed.js" async></script>
```

Скрипт вставляет виджет в рамке и сам подгоняет её высоту под содержимое.
