# Страницы судей

React-приложение, которое раздаёт сервер в зале по адресу `/judge/`. Устанавливать на планшеты ничего не нужно: достаточно браузера и Wi-Fi зала.

## Как работает

- **Секретариат** открывает `/judge/#/admin`, вводит токен секретариата, добавляет судей и печатает QR-коды. Код показывается один раз; для потерянного планшета кнопка «Новый QR-код» выдаёт новый, старый перестаёт работать.
- **Судья** сканирует QR-код и видит свой снаряд. Когда секретариат вызывает участника, на экране появляются его номер и фамилия.
  - Судья E вводит сумму сбавок.
  - Судья D вводит оценку D и нейтральные сбавки.
  - Старший судья видит оценки всей бригады и предварительный итог, а потом нажимает «Утвердить». Сервер ещё раз считает итог по правилам FIG и отправляет его на табло и сайт.
- **Без связи** оценка сохраняется на планшете (счётчик «не отправлено» в шапке) и уходит на сервер сама, когда связь вернётся. Перезагрузка страницы её не теряет. Повторная отправка не создаёт дубль.

## Разработка

```sh
pnpm --filter @ag/server start          # сервер на :3000
pnpm --filter @ag/judge dev             # страницы на :5173/judge/, запросы идут на сервер
pnpm --filter @ag/judge test
```

Сервер в зале обычно открыт по `http://`, без HTTPS. Поэтому страницы не используют возможности браузера, доступные только на HTTPS (service worker, `crypto.randomUUID`). Чтобы планшет не терял страницу, держите её открытой; оценки при этом не теряются в любом случае.
