# Лицензии: памятка владельцу программы

Программа без действующей лицензии создаёт только пробные турниры. Ключ лицензии выпускаете вы, а организатор вставляет его в секретариате, в блок «Лицензия» на экране «Соревнование».

## Как это устроено

- Ключ лицензии — строка вида `AG1.…`. Внутри записаны номер лицензии, кому она выдана и последний день срока, а в конце стоит подпись.
- Подписывает ключ **закрытый ключ выпуска** (файл `.pem`). Он есть только у вас. В программе лежит открытый ключ: им можно проверить подпись, но нельзя подписать новый ключ. Поэтому изменить в ключе срок или название, ничего не сломав, нельзя: программа такой ключ не примет.
- Проверка работает без интернета.
- Срок считается по часам компьютера. Программа помнит самое позднее время, которое видела, так что перевод часов назад срок не продлит.
- Когда срок кончился, начатые турниры работают до конца: оценки, протоколы, табло, сайт. Нельзя только создать новый турнир или загрузить турнир из файла (кроме пробного).

## Выпуск ключа

Страница выпуска и файл ключа в программу не входят: они лежат только у владельца (файлы «Выпуск лицензий.html» и `license.mjs` из проекта). Поэтому организаторы, которые получают программу, выпустить ключ не могут.

1. Откройте двойным щелчком «Выпуск лицензий.html». Подойдут свежие Chrome, Edge, Яндекс Браузер или Firefox, интернет не нужен.
2. Выберите файл закрытого ключа выпуска, впишите, кому выдаёте лицензию, и последний день срока.
3. Нажмите «Выпустить ключ», затем «Скопировать ключ», и отправьте ключ организатору.

То же из командной строки: `node license.mjs issue --key ключ.pem --org "СШОР №1" --until 2027-12-31`.

Продление — это новый ключ с новой датой: организатор просто вставляет его поверх старого.

## Берегите закрытый ключ

- Храните файл `.pem` в двух местах: на своём компьютере и на флешке или в личном облаке. Никому его не отправляйте и не кладите в папку программы. Git и сборка Docker файлы `.pem` пропускают, но лучше держать ключ отдельно.
- Если файл потерян, старые ключи продолжат работать до конца срока, но новые выпустить не получится. Тогда сделайте новую пару (`node license.mjs keygen папка`), замените `LICENSE_PUBLIC_KEY` в `apps/server/src/license/license.ts` и выпустите всем организаторам новые ключи.
- Если файл попал к постороннему, сделайте то же самое.

## Честно о пределах защиты

Лицензия останавливает обычного пользователя, который получил копию программы без вашего разрешения. Программист, у которого есть исходный код, может убрать проверку. Чтобы его было труднее достать, держите репозиторий на GitHub закрытым: `Обновить.bat` умеет скачивать обновления из закрытого репозитория по ключу GitHub (см. README).
