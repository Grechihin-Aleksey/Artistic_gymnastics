# Табло в зале

Страница для большого экрана, которую раздаёт сервер в зале по адресу `/board/`. Обновляется сама по событиям сервера, без перезагрузки.

## Что показывает

- **Сейчас на снарядах** — кто выступает на каждом снаряде и последняя утверждённая оценка (D, E, сбавки, итог). Сбавки отдельных судей E видны, только если соревнование создано с `publishJudgeMarks: true`.
- **Многоборье**, **командный зачёт** и **места на каждом снаряде**.
- Каждая новая утверждённая оценка на несколько секунд появляется крупной строкой сверху.

## Адрес

`/board/#c=<id соревнования>&view=<вид>`

| `view` | Что на экране |
| --- | --- |
| `auto` (по умолчанию) | Слайды по кругу каждые 12 секунд: снаряды, многоборье, команды, снаряды с результатами; длинные таблицы по страницам |
| `now` | Только «Сейчас на снарядах» |
| `aa` | Многоборье |
| `teams` | Командный зачёт |
| `FX`, `BB`, … | Места на снаряде |

Без `c` табло предлагает выбрать соревнование. Разные экраны в зале можно открыть с разными `view`.
